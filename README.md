# Stock-portfolio 💼

> A lightweight Python tool to record investments and instantly understand your stock portfolio.

Track what you own, how much you invested, and the total value of your holdings—all from the terminal.

---

## What it does

`Stock-portfolio` lets you enter a stock symbol, number of shares, and price per share. It then calculates the value of each holding and your overall portfolio total.

Key capabilities
Capability	Description
Record holdings	Add a stock, share quantity, and price
Calculate value	See the investment value for every stock
Portfolio overview	View your complete collection of holdings
Total investment	Get the total portfolio value instantly
